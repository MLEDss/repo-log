# 计划（现行）

> 与 `AGENTS.md`、`docs/交接文档.md`、`.cursor/rules` 冲突时先问用户。

## 目标

在 **本仓** 做以 Logseq OG 文件图为底座的引擎：对话入库、工程文档镜像、概念/案例页。入口（Logseq 插件、Cursor skill、备用控制台、ChatGPT 导出）后接同一引擎。不 fork OG。项目随时在插件里添加，不当成「待你确认的产品选型」。

## 仓内 vs 仓外

| 路径 | 谁写 |
|------|------|
| `D:\Repo Log\**`（含默认图 `out/notes`） | Agent 与测试 |
| 用户仓外 Logseq 图、`rag-inbox`、Zotero、Optics Simulation | 用户；Agent 禁止写 |

默认图由 `python -m repo_log init` 建在 `out/notes`。Agent 不创建 `D:\Knowledge`。用户若另开仓外图，自行复制或加 `--allow-external`（仅用户本机）。

## 分期

| 期 | 内容 | 完成判据 |
|----|------|----------|
| P0 | Agent 规范、交接/计划、页名与捕获骨架、拒绝仓外写入 | 本仓 unittest 绿；无仓外文件 |
| P1 | Cursor jsonl → 对话页 CLI（合成夹具） | 模板字段齐全；正文 ≤ 约 15 条 |
| P1b | Cursor / ChatGPT 工程文档单向镜像，笔记可打开计划/交接 | 源仓零写入；见 `docs/contracts/project-bridge.md` |
| P1c | `init` 产出可被 OG 打开的图；capture/catalog 默认写入该图 | `out/notes` 含 `pages/` `journals/` `logseq/config.edn`（`:triple-lowbar`）；unittest 覆盖 init 与拒仓外写 |
| P1d | 本仓控制台：设置、工程、镜像、入库、打开图 | `python -m repo_log` 打开窗口；按钮只调引擎；无第二套写页 |
| P2 | 读书笔记页：用户已整理的要点 → `文献/` / `概念/` 模板 | 不解析 PDF；只写 Markdown 页 |
| P3 | 案例短页生成器：按视频笔记 ID 填 `templates/案例.md` | 不复制逐帧表 |
| P4 | Logseq 插件按市场规范打包；上架需公开 GitHub + marketplace PR | `plugin/` 含 `@logseq/libs`、Vite `dist`、`.github/workflows/publish.yml`、MIT、icon/showcase；`effect: false`；无第二套 capture/catalog；市场目录无同类 |

## RAG

用户已有 RAGFlow 时：本仓最多 **导出脱敏 md 副本**（用户指定仓外目录时由用户跑 CLI）。本仓不实现 PDF 向量化、不启动 Docker。

## 学习用的外部项目（只读，学工具结构）

[logseq-plugin-samples](https://github.com/logseq/logseq-plugin-samples)、[logseq-wiki](https://github.com/ystreibel/logseq-wiki)。禁止把它们的运行时接进本仓 `.venv`。
