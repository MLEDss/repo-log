# 工程文档对接（Cursor / ChatGPT）

本仓生成 Logseq 可读页。工程仓仍是计划/交接的真源。

## 互不影响（硬规则）

| 禁止 | 原因 |
|------|------|
| 把工程仓当 Logseq 图根目录 | OG 会在仓内写 `logseq/`、`bak/`、`.recycle`，污染 git 与运行 |
| 把 `docs/` 符号链接进笔记图 | Logseq 可能改格式/加属性，反向写坏计划 |
| 把笔记图加进光学/LED 的 Cursor 工作区 | 索引变慢，笔记进错上下文 |
| 从笔记改镜像页并指望工程仓更新 | 镜像只读；改计划仍在对应 IDE 的仓库 |

允许：本工具**读**工程仓白名单 Markdown，**写**到笔记输出目录（本仓 `export/` 或用户图）。源仓零写入。

## 白名单（默认可进笔记）

- 仓根 `AGENTS.md`
- `docs/*.md`（计划、交接、路线图、INDEX、使用说明等）

排除：`参考文件/`、`.venv/`、源码、PDF、视频。单文件超过 256 KiB 跳过。

## 页名

- `对接/Cursor`、`对接/ChatGPT`：按 IDE 索引
- `工程/<id>`：项目页
- `工程/<id>/<相对路径去后缀>`：文档镜像，例如 `工程/led-tools-chatgpt/docs/交接文档`
