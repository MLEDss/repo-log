## 运行

```powershell
cd "D:\Repo Log"
.\repo-log.cmd
```

Logseq OG 打开 `D:\Repo Log\out\notes`，Load unpacked plugin → `D:\Repo Log\plugin`。Agent 只对 `tests/fixtures/projects` 跑 catalog，不把兄弟仓正文拷进 git。
